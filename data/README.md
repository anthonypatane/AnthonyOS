# Anthony OS Data

This folder stores the changing information used by Anthony OS.

Examples include:

- Workout history
- Current workout goals
- School assignments
- Class schedules
- Nutrition and water logs
- Smart-home device information
- Daily priorities

The dashboard, Alexa routines, automations, and future AI features should all read from this central data layer.

This folder will eventually contain separate areas for:

- Fitness
- School
- Nutrition
- Work
- Smart Home
- System settings
